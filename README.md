# Air Pollution and Respiratory Admissions in England

Explore synthetic air pollution and respiratory admissions data across seven English regions, 2015–2023.

The Python scripts generate pollutant readings and admissions counts. The 63 region-year observations support a demonstration of merging data, calculating rates per 100,000 and comparing regression models. The trends reflect the simulation assumptions.
